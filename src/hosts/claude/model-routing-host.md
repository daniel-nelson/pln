**Claude resolution.** Use `{{SKILL_DIR}}/bin/pln-model-route resolve --host claude` with the semantic profile, the current session model when the host exposes it, and current effort. Judgment always inherits the hosting model and requests at least `high` effort; an unreported or unfamiliar model name is ordinary attribution, never a dispatch gate. Opted-in evidence resolves to `sonnet` at `low` effort when that exact route is release-qualified. Economy aliases live in `src/hosts/claude/model-profiles`, not shared policy.

For native Agent or Workflow calls, omit the model option when `MODEL_ARGUMENT=inherit`; otherwise pass the returned economy model, and pass the returned effort. Never ask permission to inherit a judgment worker and never infer capability from an alias. An unavailable economy selection falls back to inherit without blocking. After completion, prefer the model/effort the host reports; otherwise record the inherited or selected alias and `underlying model unreported`.
