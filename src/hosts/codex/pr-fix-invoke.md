When a cluster returns, commit its fixed files by name with the co-author trailer — never `--amend`, never `--no-verify`, never `git add -A`. One commit per cluster, message `fix: review findings — {cluster summary}`. Write the commit hash against each of that cluster's findings in `REVIEW.md`, then start the next cluster.
