**Watch through a native resumable command session, not a subagent.** A spawned agent inherits the orchestrator's sandbox without the network access `gh pr checks` needs, so the coordinator owns the poll loop. Start that loop without shell detachment through the host's resumable exec session: let the initial `exec_command` yield a session ID while the process remains active, record that handle and `$RUN/watch.log` in the ledger, then poll the same session with bounded empty `write_stdin` calls. The loop prints only fixed state-change lines and exits on green or red; raw check output stays in the log. Never use `&`, `disown`, or a process that expects a future user turn to rediscover it.

Retain the command-session handle and keep the same parent turn active until it reaches a terminal state. A quiet poll means poll the same handle again; it is not permission to summarize, promise future monitoring, or send a final response. When the command exits, send `$RUN/watch.log` to an evidence worker for fixed terminal-state/check/duration metadata; never read or tail the raw log in coordinator context. Escalate ambiguous or contradictory state to judgment.

When the validated envelope shows a terminal state:

- **Green** — undraft and record the duration as described above, then fire the completion notification.
- **Red** — build the finding, write it into `REVIEW.md`, then dispatch the one fix cluster natively, the same way Step 4 already does: `spawn_agent` with a fresh context, `wait_agent`-looped to completion, per Spawning a fresh-context agent and `pr-fix-invoke` — including its `BLOCKED:` handling. This part needs no shell fallback; a fix agent only writes files and needs no network. Once it returns and its commit is pushed, start a fresh resumable command session for the next watch round; never reuse a poll process across candidates.

Track the same-check streak and the `BLOCKED:` case across rounds in the orchestrator's own context (this session, not the background script) — that bookkeeping is what decides when to stop instead of relaunching another round.
